# Hot Wheels 原型

这是一个使用 Bun、Vite、React 和 Three.js 构建的小型 Hot Wheels 风格赛车原型。

游戏效果图：`target.png`

## 当前进度

当前原型已经实现：

- 蓝色盒子占位车辆。
- WASD 驾驶控制。
- 与车辆前进方向和赛道法线对齐的跟随镜头。
- 橙色塑料赛道、中心线和护栏。
- 使用切线、法线和副法线局部坐标帧的 3D 赛道扫掠流程。
- 玩家车辆基于赛道距离前进，并贴合赛道的局部坐标帧改变高度和姿态。
- 支持立体直道、坡道和带倾角的弯道。
- 固定长测试赛道，长度约 5,620 个世界单位，正常驾驶目标约 60 秒左右。
- 速度 HUD。

## 赛道生成

赛道由代码生成，不依赖外部模型文件。

当前实现：

- `TrackBuilder` 保存采样后的中心线路径节点。
- `straight()` 生成沿当前朝向前进的立体直道。
- `slope()` 生成带平滑高度变化的坡道。
- `bankedArc()` 生成水平圆弧路径，并让路面倾角在弯中平滑进入和退出。
- 每个采样点包含 `position`、`tangent`、`normal`、`binormal`、`banking` 和累计 `distance`。
- `sampleTrackAtDistance()` 可以按赛道距离插值采样局部轨道帧。
- 路面、中心线和护栏会基于生成的中心线，使用局部 3D 坐标帧扫掠生成。
- `buildTrack()` 当前加载固定长测试赛道，方便手动验证坡道和倾角弯体验。
- `generateRandomTrackSamples()` 仍保留固定种子的随机平面赛道生成逻辑，后续可以重新接入或升级为 3D 随机生成。

## 操作

- `W`：加速
- `S`：倒车 / 刹车
- `A`：向赛道左侧移动
- `D`：向赛道右侧移动

## 验证

当前原型通过：

```bash
bun run build
```

如需完整检查，也可以运行：

```bash
bun run lint
```

之后等待用户手动测试。
