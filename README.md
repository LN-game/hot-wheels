# Hot Wheels Prototype

A small Hot Wheels-style racing prototype built with Bun, Vite, React, and Three.js.

## Current Step

Step 1 is implemented:

- Blue box placeholder car
- WASD driving controls
- Follow camera behind the car
- Procedural orange plastic track
- Simple generated straight section plus curved sections
- Speed HUD

## Controls

- `W`: accelerate
- `S`: reverse / brake
- `A`: steer left
- `D`: steer right

## Validation

The current prototype passes:

```bash
bun run lint
bun run build
```

然后等待用户手动测试
