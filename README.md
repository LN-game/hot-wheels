# Hot Wheels 原型

这是一个使用 Bun、Vite、React 和 Three.js 构建的小型 Hot Wheels 风格赛车原型。

游戏效果图：`target.png`

## 当前进度

当前原型已经实现：

- 蓝色盒子占位车辆。
- WASD 驾驶控制，A/D 使用轨道坐标下的简化车辆转向模型。
- 与车辆前进方向和赛道法线对齐的跟随镜头。
- 橙色塑料赛道、中心线和护栏。
- 使用切线、法线和副法线局部坐标帧的 3D 赛道扫掠流程。
- 玩家车辆基于赛道距离和横向偏移前进，并贴合赛道的局部坐标帧改变高度和姿态。
- 玩家车辆拥有相对赛道切线的车头偏角，转向会先改变车头角，再按车头方向分解为沿赛道和横向运动。
- 支持立体直道、坡道和带倾角及高低变化的弯道。
- 支持垂直回环赛段，车辆会沿赛道局部法线完成倒置翻转。
- 固定长测试赛道包含更大半径、更长弧长和更明显高低差的倾斜弯道。
- 固定长测试赛道开头加入了一个较大的侧向错开垂直回环。
- 速度 HUD。

## 赛道生成

赛道由代码生成，不依赖外部模型文件。

当前实现：

- `TrackBuilder` 保存采样后的中心线路径节点。
- `straight()` 生成沿当前朝向前进的立体直道。
- `slope()` 生成带平滑高度变化的坡道。
- `bankedArc()` 生成带倾角的圆弧弯道，并支持弯道自身平滑升高或降低。
- `verticalLoop()` 生成弹簧式空间垂直回环：车辆完整绕一圈，同时出口相对入口侧向错开，避免入口和出口落在同一个平面圆环上。
- 路面基准法线按当前切线和世界上方向重新计算，弯道只在当前采样点应用 `banking`，避免倾角泄漏到后续直道。
- 回环采样点会写入自定义路面法线，确保回环顶部车身和护栏随赛道一起倒置。
- 每个采样点包含 `position`、`tangent`、`normal`、`binormal`、`banking` 和累计 `distance`。
- `sampleTrackAtDistance()` 可以按赛道距离插值采样局部轨道帧。
- 路面、中心线和护栏会基于生成的中心线，使用局部 3D 坐标帧扫掠生成。
- `buildTrack()` 当前加载固定长测试赛道，方便手动验证坡道和倾角弯体验。
- `generateRandomTrackSamples()` 仍保留固定种子的随机赛道生成逻辑，弯道候选已改为使用 `bankedArc()`，后续可以升级为完整 3D 随机生成。

## 操作

- `W`：加速
- `S`：倒车 / 刹车
- `A`：向左打方向
- `D`：向右打方向

松开 `A` / `D` 后，车头偏角会保持在最后的角度，不会自动回正。

## 验证

当前原型通过：

```bash
bun run build
```

如需完整检查，也可以运行：

```bash
bun run lint
```

之后等待用户手动测试。
